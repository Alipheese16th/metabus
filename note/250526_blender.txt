# 매시 맵 베이커
Normal (곡률 맵): 법선
World space normal (실제 공간 표준 맵):
ID (색상 맵): 떨어져있을때 색상으로 표현
Ambient occlusion (주변 폐색 맵): 오브젝트끼리 겹쳐졌을때 사이의 어두움
Position (위치 맵): 위치정보
Thickness (두께 맵): 두께의 깊이
Opacity : 찢어진거 표현할때ㅐ

# 레이어
주로 채우기 레이어를 쓴다
매터리얼을 채운다
채우고나서 이 영역만 적용한다. (마스크 중심의 텍스쳐링)

처음엔 재질을 color, rough, metal 3개
질감과 색상.

# 기본 색상 레이어
피부색상을 적용해보면 전체 다 칠해져있다.
마스크를 추가해서 원하는곳만 적용해야함
레이어 우클릭 - 검정 마스크 추가 - 마스크 우클릭 - 색상 선택 추가 - 스포이드로 원하는 피부만 선택

질감은 러프니스 조정 (샘플 데이터 스킨관련 확인해보면 러프니스 0.36 정도임)

# 디테일 레이어
또한 채우기 레이어 하나 또 추가해서
디테일 레이어를 추가한다.
똑같이 원하는 매쉬만 색상 선택으로 마스크 적용하고
노이즈를 적용해준다 (Multiply , 투명값 16 정도로 적당히 조절)

# 볼 터치 추가 레이어
채우기 레이어 또 추가해서 검정마스크 추가하고 이번엔 마스크 우클릭 - 페인트를 추가
원하는 부분만 색상 페인트 칠 하고 레이어의 멀티플라이,투명도 조절
검정마스크 - 필터 추가 해서 Blur 필터 추가하면 더 부드럽게 적용된다


# 지금껏 레이어 추가할때마다 색상 선택 해서 원하는 매쉬만 적용했는데 그거 다 지우고

# 헤어 레이어 (마스크 색상선택 헤어만)

- Height 채우기 레이어 (height)

- Anisotropic Noise 음영 적용하는데 Roate 키면 세로로 주름지는거 볼수있음

다 적용했으면 height 값 적절히 적용
