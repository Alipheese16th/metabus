
# 에너미의 걷기, 달리기 애니메이션 적용

Animator 에서

Blend Tree 노드를 하나 생성

걷기 애니메이션 클립과, 달리기 애니메이션 클립을 연결하자.

그러면 Blend 수치가 0~1 조정할때 서로 애니메이션 비중이 바뀜

즉 스피드값을 변수로서 0~1로 조절하면 걷느냐 달리느냐를 조절할수있다는것


% Animator.StringToHash 
애니메이터의 파라미터를 문자열로 찾기보단 해쉬주소로 찾는게 성능상 빠름

각 상황에 따라 애니메이터에 파라미터 변수를 넣어줘서 애니메이션 변경을 구현

이제 잘 움직이는데 문제는 날 인식하고 따라올때 회전이 다 안됐는데 움직이는게 비자연스러움

NavMeshAgent 의 updateRotation 를 false 해주고 (이제 스스로 회전 안한다.)

damping 이라는 float 변수를 하나 만들어두고

순찰시 1, 추적시 7 정도 값 부여

% Transform 의 LookAt 은 내가 바라보는 방향을 지정한 방향으로 변경함.

% Quarternion LookRotation 은 내가 바라보는 방향과 지정한 방향의 사이 값을 구함

NavMeshAgent 의 desiredVelocity 값이 목표로 향하는 방향임.
그냥 velocity 는 현재 속도기때문에 벽에 껴있으면 0임


# 사격 추가

Any State 노드에 사격 애니메이션 연결
나갈때는 다시 AnyState로 못돌아감. 각 스테이트로 연결해줘야함

그리고 파라미터 하나 생성. 트리거로 구현. 일방통행임. 

Transition Duration 값을 줄여줘야 바로 사격액션이 강하게 나옴.

초당 10발 ~ 3발 적용해보기.

Animator 의 SetTrigger 로 발동하면 애니메이션 실행.

기존 장전 애니메이션은 앉아서 장전한다.
특정 본만 가져오고싶은경우도 가능하다

# 아바타 마스크

아바타마스크를 하나 새로 생성

사용 안할 부위를 특정할수있음. (선택 안한부분만 사용)

% IK / FK
Inverse Kinematic / Forward Kinematic

IK : 손을 책상에 올려놓으면 몸이 움직여도 손은 반작용으로 고정되는것.

에니메이터의 레이어를 하나 새로 만들어서 설정에서 아바타 마스크를 적용하면 그 레이어에서는 마스크된 본만 애니메이션함.
